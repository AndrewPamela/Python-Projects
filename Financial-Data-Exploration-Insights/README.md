# Financial Data Exploration & Insights

## Project Overview

This Python project explores financial transaction data to identify patterns in spending, departmental activity, regional performance, payment methods, account types, and budget utilisation.

The analysis involved examining transaction-level data and using Python to transform the raw dataset into meaningful financial insights that can support business reporting and decision-making.

## Business Objectives

The analysis focused on understanding:

* Overall transaction and spending patterns
* Financial performance across departments
* Regional transaction activity
* Transaction types and payment methods
* Account-type behaviour
* Spending compared with annual budgets
* Trends in financial activity over time

## Analysis Performed

### Financial Overview

Analysed transaction amounts to understand overall financial activity and identify major spending patterns.

### Department Analysis

Compared transaction values across departments to identify departments with higher financial activity and potential areas requiring closer monitoring.

### Regional Analysis

Examined transaction activity across regions to identify differences in financial performance and spending behaviour.

### Transaction Analysis

Analysed different transaction types to understand how financial activity was distributed across the dataset.

### Payment Method Analysis

Compared payment methods to understand how transactions were completed and identify the most frequently used methods.

### Account Analysis

Examined account types to identify differences in transaction activity and financial behaviour.

### Budget Analysis

Compared transaction amounts with annual budget values to provide a view of spending relative to available budgets.

### Time-Based Analysis

Explored transaction activity by date to identify changes and trends in financial activity over time.
