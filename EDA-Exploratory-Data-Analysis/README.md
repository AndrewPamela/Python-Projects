# EDA – Exploratory Data Analysis

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) using Python to examine, understand, and visualise a dataset before deeper analysis or modelling.

The project involved exploring the structure and quality of the data, identifying patterns and distributions, analysing relationships between variables, and using visualisations to communicate findings.

## Objectives

The analysis was designed to:

* Understand the structure and characteristics of the dataset.
* Identify missing values and data-quality issues.
* Explore distributions and patterns within the data.
* Analyse relationships between important variables.
* Identify trends, outliers, and notable observations.
* Communicate findings through clear visualisations.

## Analysis Performed

### Data Exploration

Examined the dataset structure, columns, data types, summary statistics, and general characteristics of the data.

### Data Quality Assessment

Checked for missing values, duplicates, inconsistencies, and other potential data-quality issues that could affect analysis.

### Descriptive Analysis

Used statistical summaries and grouped analysis to understand the distribution and behaviour of key variables.

### Relationship Analysis

Explored relationships between variables to identify patterns, differences, and potential associations within the dataset.

### Data Visualisation

Created charts and visualisations to make patterns, distributions, and relationships easier to understand.
