# Sales Data Analysis with Python

## Project Overview

This project analyses sales transaction data using Python to understand sales performance, customer segments, regional activity, product performance, discounts, and purchasing behaviour.

The analysis uses transaction-level data to identify patterns and relationships that can support sales reporting and business decision-making.

## Dataset

The dataset contains the following fields:

* `Order_ID`
* `Date`
* `Product`
* `Region`
* `Customer_Segment`
* `Channel`
* `Quantity`
* `Discount`
* `Unit_Price`
* `Sales`
* `Customer_ID`

## Analysis Performed

### Sales Performance Analysis

Analysed sales performance across regions and customer segments using grouped summaries and calculated metrics.

### Product and Quantity Analysis

Examined quantities sold and their relationship with sales values.

### Regional Analysis

Compared sales activity across regions to identify differences in performance.

### Customer Segment Analysis

Explored sales behaviour across different customer segments.

### Discount Analysis

Examined discount levels in relation to sales activity.

### Data Visualisation

Created visualisations to make sales patterns and relationships easier to interpret.
